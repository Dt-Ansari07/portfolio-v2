# Zulfiqar Ansari Portfolio

A modern, production-ready portfolio built with **Next.js 16**, **React
19**, **TypeScript**, and **Tailwind CSS v4**.

Designed to showcase professional experience, technical skills, and
real-world data analytics projects through a fast, responsive, and
accessible web application.

## 🚀 Getting Started

### Prerequisites

-   Node.js 20+
-   npm

### Installation

``` bash
git clone https://github.com/YOUR_USERNAME/portfolio.git
cd portfolio
npm install
cp .env.example .env.local
```

Configure:

``` env
RESEND_API_KEY=
CONTACT_EMAIL_TO=
NEXT_PUBLIC_SITE_URL=
```

------------------------------------------------------------------------

## 💻 Development

``` bash
npm run dev
```

Open: <http://localhost:3000>

------------------------------------------------------------------------

## 📦 Production Build

``` bash
npm run build
node .next/standalone/server.js
```
